## hub
```
开
rmmod gpio_pca953x 2>/dev/null
i2cset -y 0 0x26 0x07 0x00
OLD=$(i2cget -y 0 0x26 0x03); i2cset -y 0 0x26 0x03 $((OLD | 0x40))
关
OLD=$(i2cget -y 0 0x26 0x03); i2cset -y 0 0x26 0x03 $((OLD & ~0x40))
加载
modprobe gpio_pca953x
```
